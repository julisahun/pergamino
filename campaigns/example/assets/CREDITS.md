# Credits

All five images in this folder are placeholder art generated for this
example campaign — a flat colour, a border, and the scene's own name and
one-line description, produced with Pillow. No illustration, no external
source, nothing to attribute.

Swap any of them for real art at any time: the scene files reference them by
path (`assets/<name>.jpg`), so replacing the file is enough — no JSON needs
to change unless the filename does too.
